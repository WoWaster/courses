# Структура слайдов

- Какие есть инструменты
- Мотивировка: форматтер, анаизаторы, тесты, CI (~4 слайда)
- Подробности
  - Форматтер: что такое, зачем нужно, примеры на python, C, kotlin, rust, pascal
  - Code style
  - Анализаторы: статические, динамические. Система типов как способ статического анализа
  - Примеры на конкретных ЯП
  - Тесты, введение, 4-5 слайдов (из слайдов Ефима)
  - Методология TDD
  - CI. Что такое, не только про github actions. CI как инструмент автоматизации и формализации общих правил
- Зачем нужны анализвторы, тесты и CI в эпоху ИИ. Чем полезны, почему TDD снова актуален. (ai-xp)
